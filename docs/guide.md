# 使用指南

## 快速开始

### 1. 注册账号
访问 `/register` 页面，填写用户名、密码和邮箱(可选)进行注册。

### 2. 登录
访问 `/login` 页面，使用注册的账号登录。

### 3. 发布帖子
点击导航栏的 "📝 发帖" 按钮，填写标题和内容后发布。

### 4. 回复帖子
点击帖子进入详情页，在底部输入回复内容。

### 5. 管理帖子
- 自己的帖子可以删除
- 管理员可以删除所有帖子

## 功能介绍

### 首页
- 显示所有帖子列表
- 支持分页浏览
- 置顶帖子优先显示

### 帖子详情
- 显示完整内容和所有回复
- 可以发表回复
- 作者可以删除帖子

### 个人主页
- 显示用户信息
- 查看自己的帖子和回复统计

### 管理后台 (管理员)
- 查看统计信息
- 管理所有帖子

## 常见问题

### 忘记密码怎么办？
目前版本不支持密码重置，请联系管理员。

### 如何成为管理员？
在数据库中手动设置 `users` 表的 `is_admin` 字段为 `1`。

### 数据存储在哪里？
数据存储在 `database/forum.db` SQLite 文件中。
